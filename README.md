# 🎓 Sistema Escolar

### Um sistema simples de gerenciamento escolar desenvolvido em Java.

</div>

---

<div align="center">

## 📚 Sobre o Projeto

</div>

O **Sistema Escolar** é um projeto desenvolvido com o objetivo de praticar e aplicar conceitos fundamentais da linguagem Java.

O sistema permite realizar o cadastro e o gerenciamento de alunos, armazenar notas, buscar alunos através da matrícula e verificar a situação final de cada aluno com base em sua média.

---

<div align="center">

## ✨ Funcionalidades

</div>

* 👨‍🎓 **Cadastrar alunos**
* 🔢 **Gerar matrícula automaticamente**
* 📋 **Listar alunos cadastrados**
* 🔎 **Buscar aluno pela matrícula**
* 📝 **Adicionar 3 notas para cada aluno**
* 📊 **Exibir as notas do aluno**
* 🧮 **Calcular a média das notas**
* 🎯 **Verificar a situação do aluno**

<div align="center">

### 📌 Situação do Aluno

</div>

|      Média      |    Situação    |
| :-------------: | :------------: |
|     `≥ 7.0`     |   🟢 Aprovado  |
| `≥ 5.0 e < 7.0` | 🟡 Recuperação |
|     `< 5.0`     |  🔴 Reprovado  |
